IT event equipment request form

English

This form is for requesting IT devices for a specific event. Your request will be submitted to the IT department for approval.
Required fields are marked with an asterisk (*).

Note: All requests must:

  • comply with the internal DG-ITEC Service Level Agreement (SLA) (which defines service deadlines)
  • respect the Configuration Management Database (CMDB) asset mapping protocol (used for tracking equipment inventory)

Français

Ce formulaire permet de demander des appareils informatiques pour un événement spécifique. Votre demande sera soumise au département informatique pour approbation.
Les champs obligatoires sont marqués d'un astérisque (*).

Remarque : Toutes les demandes doivent :

  • être conformes à l'accord de niveau de service (SLA) interne de la DG-ITEC (qui définit les délais de prestation)
  • respecter le protocole de cartographie des actifs de la base de données de gestion des configurations (CMDB) (utilisé pour le suivi de l'inventaire des équipements)

Deutsch

Dieses Formular dient der Anforderung von IT-Geräten für eine bestimmte Veranstaltung. Ihr Antrag wird der IT-Abteilung zur Genehmigung vorgelegt.
Pflichtfelder sind mit einem Sternchen (*) gekennzeichnet.

Hinweis: Alle Anträge müssen:

  • der internen Service-Level-Vereinbarung (SLA) der GD ITEC entsprechen (welche die Servicefristen festlegt)
  • das Asset-Mapping-Protokoll der Configuration Management Database (CMDB) einhalten (das für die Verfolgung des Gerätebestands verwendet wird)
